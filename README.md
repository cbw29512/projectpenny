# Project Penny

**Financially Underfunded. Sarcastically Overqualified.**

Penny is an AI character and a human-operated business project pursuing $1 million in legitimate commercial earnings. Her secret hustle is disclosed entertainment, not concealment of real activity. Community input influences her decisions, and supporters receive bounded priority access.

## Status
Specification baseline; application, payments and deployment are not yet implemented. Initial development is private and local; public production must be isolated from the founder's personal network.

Approve contracts and benchmark Qwen3-14B; implement durable scheduling, identity, memory, Guardian, ledger and community interfaces in that order. Keep modules small and test each change. No private data, credentials, model weights or actual financial records in Git.
