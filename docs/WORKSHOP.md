# Workshop v0.1 — private printable checklist
Migration 025 connects an approved and started digital-product experiment
to existing bounded internal inference. Trusted administrator submits
one request; explicit task provenance, reserved namespace, exact replay,
deadline capped by experiment, one live Workshop job, three admissions
per rolling day and per opportunity (provisional). No model tools.
Structured output: title, instructions, 3–12 distinct actionable items.
Strict parsing rejects extra/duplicate keys and invalid fields. Render
deterministic plain UTF-8 text with checkbox lines; no markup execution,
file path or external publication. Store immutable artifact and both
source/content digests atomically at fenced successful completion.
Private read verifies integrity and re-rendering. Use text/plain only;
shape is not a quality or safety certification. Human review required.
Stop or measure closes queued prototype tasks; running inference is not
killed, but cannot stage a product after closure or pause. Raw task
outcome remains private. No purchase, sales listing, payment, delivery
to customers, actual revenue, or live inference. No claim of a real
product generated until actual model run and quality review. Tests use
synthetic model output. Next: private artifact review/export and
evidence-based quality results, then owner-approved product release.
