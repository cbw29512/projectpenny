# Bit — Penny's desktop buddy
Maker-approved concept. Bit (Binary Intelligent Teammate) is a fictional
virtual companion, not an independently running AI agent or a real purchase.

## State and authority
- Fixed character ID bit-v1, approved local art and dedicated bit-dock slot.
- Eligibility: $500 (50,000 cents) in lifetime reconciled net commercial
  receipts (commercial receipts minus commercial refunds); not cash,
  profit, founder income, funding or donations. Metric choice is explicit
  and does not redefine the separate million-dollar mission.
- Reuse the reviewed finance snapshot, reconciliation and Guardian admin
  review. Acquisition binds exact source digest under scheduler lock.
  The existing immutable world journal records acquire then place.
  Eligibility is not ownership. Replay is idempotent. A stale feed or later
  ordinary refund does not silently remove an earned companion. A mistaken
  reward can be explicitly stored/removed with reviewed correction evidence.
- Bit cannot own funds, access tools, modify the world or start inference.

## Coded reactions
Fixed local expressions: idle, attentive, celebrating, confused, charging.
A fresh exact reviewed activity snapshot can trigger working/answering,
verified sale or achievement, error, or actual asleep state. Event
celebration/error expires after 15 seconds; activity after 60 seconds.
Unknown, missing, stale or malformed data defaults to idle; no fake
transaction or work claims. Hidden tabs stop updates; reduced motion
disables the celebration animation. The world snapshot alone controls
visibility, never the reaction snapshot. No activity producer is installed
yet: checked-in snapshot is unavailable. No live approval or unlock.

Future milestone upgrades: $750 charging station, $1,500 extra expressions,
$2,500 mobility, $5,000 accessories, $10,000 interaction animations.
All future tiers require separate reviewed implementation, no new spend.
Future merchandise must use approved consistent Bit/Penny brand art and
the existing Office Collection contract. No actual merchandise enabled.
